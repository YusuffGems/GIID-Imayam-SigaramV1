# Project notes

Self-hosted TanStack Start + Vite project. No Lovable dependency.

- `npm run dev` — local dev server on http://localhost:8080
- `npm run build` — production build (Vercel output, see vite.config.ts)
- `npm run lint` / `npm run format`

Deployment target is set by the `nitro.config.preset` value in vite.config.ts.
See VERIFICATION.md for what has been tested and what has not.

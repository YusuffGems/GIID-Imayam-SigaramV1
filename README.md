# Crafted Purpose

# GIID Imayam Sigaram — Premium Artisan Leather & Handmade Products E-Commerce Website

## MASTER WEBSITE DEVELOPMENT PROMPT

Create a complete, production-ready, premium ecommerce/catalog website named **“GIID Imayam Sigaram”** for showcasing and selling handmade leather goods and other handcrafted products created through a social-impact initiative.

The website must feel like a **premium international artisan lifestyle brand**, while clearly communicating that the products are made by **Differently Abled and Persons with Disabilities / beneficiaries**, giving them skills, dignity, livelihood opportunities and sustainable income.

Use the provided Zygma website only as a **UX/content-structure reference** for premium leather ecommerce presentation. Do NOT copy its branding, layout, source code, text, images, colors, or visual identity.

Reference website:
https://zygma.in/

The final website must be completely original.

---

## 1. CORE OBJECTIVE

Build a modern premium ecommerce website where:

* Customers can browse products without creating an account.
* No login is required.
* No customer registration is required.
* Customers can search, filter and sort products.
* Every product has its own detailed product page.
* Products support multiple images.
* Products support product videos.
* Customers can select quantity/options where applicable.
* Clicking **“Buy on WhatsApp”** opens WhatsApp with an automatically generated message containing the selected product details.
* Customer details can be collected through a lightweight enquiry/order form.
* The form should automatically prepare the WhatsApp message.
* The enquiry/order information should also be stored automatically in Google Sheets through Google Apps Script.
* Include floating WhatsApp and Call buttons on desktop and mobile.
* Mobile navigation must be a responsive floating navigation system.
* Product cards must be premium, clean and easy to understand.
* Website must be fast, responsive and SEO-friendly.
* Website must deploy cleanly on Vercel.

## Running this project

    npm install
    npm run dev      # http://localhost:8080
    npm run build    # production build
    npm run lint
    npm run format

## Deployment

The build target is set by the `preset` value passed to `nitro()` in
vite.config.ts:

- `"vercel"`     - current setting; outputs to .vercel/output
- `"cloudflare-module"` - Cloudflare Workers/Pages
- `"node-server"` - a plain Node server you run yourself

## Environment variables

Copy `.env.example` to `.env.local` and fill in:

- `GOOGLE_APPS_SCRIPT_URL` - Apps Script web app that writes enquiries to the
  Google Sheet (server-side only, never exposed to the browser)
- `GOOGLE_APPS_SCRIPT_TOKEN` - optional shared secret; leave blank unless the
  Apps Script sets one too
- `VITE_SITE_URL` - production origin for canonical URLs, Open Graph and
  sitemap.xml

On Vercel, set the same names under Settings > Environment Variables, then
redeploy.
